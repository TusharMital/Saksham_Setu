# Saksham_Setu(साक्षम सेतु)
AI-powered portal that helps Scheduled Caste entrepreneurs find the right government loan scheme, locate a partner bank with available funds, and track their application. Includes Sarthi, a Groq-powered multilingual chatbot. Built for the Prompt Engineering final project.
# Problem
NSFDC finance is routed through 100+ channel partners. Applicants don't know which 
scheme fits them or which partner can serve them, so applications are misrouted, sit 
at branches with no funds, and get rejected without explanation.
# Target users
Rural and semi-urban SC entrepreneurs and students with low digital literacy.
